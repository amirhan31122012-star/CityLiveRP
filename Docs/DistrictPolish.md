# 1.2.1: заставка, руление и освещение

1. Закройте Unreal. Обновите ветку в GitHub Desktop: Fetch origin → Pull origin.
   При конфликте DefaultEngine.ini: Branch → Stash All Changes, затем Pull.
2. Запустите UpdateDistrictPolish.cmd. Он собирает код и обновляет свет в
   установленном районе. FBX/текстуры повторно не импортируются. Карта сохраняется
   в резервную копию CityLive_BeforePolish_<номер> перед изменением освещения.
3. После «Готово» проверьте через BuildAndOpen.cmd. Затем закройте Unreal и
   запустите BuildAndroidV1Shipping.cmd. Установите APK 1.2.1-test (StoreVersion=6)
   поверх прежней игры с той же подписью. ImportPoliceDistrict.cmd повторять не нужно.

Заставка: CITYLIVE RP перемещена в центральную безопасную область над синей
машиной. Ресурсы landscape/portrait и downloadimage обновлены вместе.

Руление: максимальный запрос на малой скорости 65°/с вместо 55°/с. Визуальный
поворот передних колёс 34° вместо 28°. Городской предел бокового ускорения
увеличен с 600 до 680 см/с² и плавно возвращается к 600 на максимальной скорости.
Небольшое отклонение джойстика применяется после ограничения по скорости, поэтому
10% стика остаются 10% запроса, а не достигают преждевременно полного поворота.
Сглаживание ввода и физика подвески сохраняются.

Освещение: тени направленного света остаются включёнными. Skylight получает
интенсивность 2.2 и светлый нижний полупространственный цвет вместо чёрного.
Так усиливается окружающий свет в тенях и на стенах. Материалы домов, дальность
прорисовки и RendererSettings не меняются. Эффект на далёких фасадах необходимо
проверить на устройстве: без снимка нельзя исключить и другие причины затемнения.

Новые импорты сразу получают этот свет. Для существующей карты APK-проверка
требует lighting_revision=1. Логи обновления: Saved/PoliceDistrictPolish/<номер>/
Build.log и Import.log. Текущая карта после Pull восстанавливается в startup keys.

Проверены C++-расчёты лимита руления, малые отклонения на разных скоростях,
симметрия и прежние переходы педалей; проверки импорта с подменой Unreal API.
Unreal C++, реальная управляемость, свет и кадрирование заставки на телефоне
в облаке не проверялись. Окончательную оценку делаем после установки APK.
