# CityLive RP 1.2 — новая основная карта

Утверждённый район с полицией, жилыми домами, дорогами, зелёными дворами и
детской площадкой заменяет прежний Modern City при запуске проекта и APK.

1. Закройте Unreal. В GitHub Desktop выберите feature/android-touch-controls,
   Fetch origin → Pull origin. Если мешает изменённый DefaultEngine.ini,
   Branch → Stash All Changes → Pull origin. Старый renderer config обратно
   поверх обновления не восстанавливайте; импорт сам выставит новую карту.
2. Запустите ImportPoliceDistrict.cmd и дождитесь «Готово».
3. Запустите BuildAndOpen.cmd для проверки в редакторе.
4. Закройте Unreal и запустите BuildAndroidV1Shipping.cmd. Установите полученный
   APK из новой папки Releases/AndroidV1/Shipping/<номер> поверх установленной
   игры с прежней подписью. Версия 1.2.2-test, StoreVersion=7.

Blender, повторная обработка старого города, RestoreCityV1 и UpdateCityV11
для этой установки не нужны. SDK/NDK/JAVA_HOME остаются прежними.
Импортёр использует уже подготовленные Assets/Maps/PoliceDistrictGame.
При ошибке пришлите Saved/PoliceDistrictImport/<номер>/Build.log или Import.log.

## Как происходит замена

Новый уровень получает уникальную папку Run. После успешного сохранения
меняются EditorStartupMap, GameDefaultMap, Saved/ModernCityMap.txt и CityV11.json.
Прежний уровень не удаляется с диска, но больше не является стартовым и не
передаётся в -map для готовки. Папки CityLiveMaps нет в DirectoriesToAlwaysCook.
Файлы предыдущей карты остаются резервом; её marker сохранён в
Saved/PoliceDistrictPrevious.json и в журнале конкретного импорта previous.json.

Внутреннее имя нового уровня CityLive_ModernCity сохранено для совместимости
существующих скриптов. Это новый район, не прежняя геометрия Modern City.
APK-проверка требует source=PoliceDistrict и совпадения хеша manifest.json
с установленной картой. Случайно собрать версию 1.2 со старым городом нельзя.
Поле version=1.1.2 в CityV11.json означает версию прежней миграции графики,
а не отображаемую версию APK. Настройки RendererSettings не меняются.

## Игровые материалы и геометрия

FBX: 151502 треугольника, 766 пространственных групп, 26 материалов.
Фотографические текстуры, цвета газона, мелкий рельеф штукатурки/кирпича,
шероховатость и резиновая плитка запечены в обычные PBR-карты. Цвет, normal и
упакованные roughness/metallic передаются отдельно от FBX, поэтому цвета
не зависят от автоматического перевода Blender-шейдеров импортёром.
Маска листвы сохранена в альфа-канале; в игре используется masked-материал.
Текстуры 1K, газон 2K; дополнительное снижение из старого оптимизатора
к этому набору не применяется. Цветовое пространство и нормали заданы явно.
Производные текстуры основаны на CC0-ресурсах Poly Haven; исходные ссылки
находятся в Assets/Maps/PoliceDistrictRealistic/TextureCredits.json.

Дороги, земля, дома, бордюры и стволы получают статическую коллизию по
треугольникам. Трава, листва, разметка и декоративные детали её не получают.
Спавн ищется на дорожном покрытии около полиции, с проверкой площадки 5 м
и свободных проходов 6 м на двух высотах. Масштаб проверяется по ширине района.
Существующий игровой контроллер создаёт прежний управляемый Sedan рядом
с персонажем. Декоративные машины в этом наборе отсутствуют.
Новое небо использует прежний совместимый с мобильным материал IsSky.

## Проверка

В облаке выполнены: запекание Blender, контрольные суммы файлов, обратный импорт
FBX с проверкой масштаба, 766 сеток / 151502 треугольников, UV и слотов материалов.
BakedPreview.png — рендер именно повторно импортированного FBX с игровыми
текстурами; это не скриншот Unreal. Процедурная вариация ограничена повторяемыми
текстурами, поэтому не повторяет исходную сцену попиксельно.
Проверки с подменой API Unreal подтверждают переключение только после сохранения,
отказ при повреждённом пакете/отсутствии коллизии, сохранение прежних marker при
ошибке и профили NoCollision для декоративных сеток.

Настоящий импорт Unreal, готовка Android, освещение, коллизии и FPS на телефоне
ещё требуют проверки на компьютере пользователя. 60 FPS не гарантируются.

Пересборка пакета разработчиком, если изменена утверждённая сцена:

```sh
blender -b Assets/Maps/PoliceDistrictRealistic/CityLive_PoliceDistrict_Realistic.blend -t 6 --python-exit-code 1 --python Scripts/BakePoliceDistrict.py -- Assets/Maps/PoliceDistrictGame
```

`--reuse-materials` разрешён только при неизменном SHA256 исходного .blend;
он пересобирает геометрию/группы коллизий, используя предыдущие запечённые карты.

Обновление установленного района до 1.2.1: UpdateDistrictPolish.cmd, затем
BuildAndroidV1Shipping.cmd. Повторный импорт города не требуется. Docs/DistrictPolish.md.

1.2.2: положение машины и экран загрузки с процентами — Docs/LoadingAndVehicle.md.
Для установленного города выполните UpdateDistrictPolish.cmd перед сборкой APK.
