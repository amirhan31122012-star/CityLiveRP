# CityLive RP 1.1 — первое обновление Android

1. Закройте Unreal, обновите feature/android-touch-controls в GitHub Desktop.
2. Запустите UpdateCityV11.cmd. Он собирает редактор, копирует текущую карту в
   CityLive_BeforeV11 (однократно), обновляет её и записывает Saved/CityV11.json.
   Исходники города и игровые модели не меняются. Blender не запускается.
3. После «Готово» можно проверить игру через BuildAndOpen.cmd, закрыть редактор
   и запустить BuildAndroidV1.cmd. Повторная обработка города не требуется.
4. Новый APK имеет прежний пакет com.cityliverp.game, StoreVersion=2,
   VersionDisplayName=1.1.0-test. Установите поверх V1 с той же подписью сборки.
   Если установщик сообщает конфликт, пришлите точный текст; заранее удалять V1
   не нужно. Если сборка упадёт, пришлите Saved/BuildAndroidV1.log.

## Изменения

- Плавающий джойстик: захват в нижних 45% левых 40% экрана. Центр на месте
  касания, движение начинается при смещении, отпускание обнуляет ввод.
  Правый свайп камеры, педали, двери, двойное нажатие для приседания сохраняются.
- Последняя нажатая сенсорная педаль выбирает намерение движения. Отпускание
  прежней педали не отменяет новую. Газ при заднем ходе тормозит до нуля и затем
  ускоряет вперёд без повторного нажатия. При скорости заднего хода 14.4 км/ч
  расчётное торможение занимает ~0.33с при полной передаче усилия на грунт;
  реальные контакты/склон могут изменить время. Физическое ограничение силы
  сохраняется. Тормоз аналогично останавливает и включает медленный задний ход.
- UpdateCityV11 удаляет только StaticMeshActor с отдельными автомобильными
  сетками Cars/Car/Vehicle/Bus/Truck/Van, включая Parking_Block_Cars. Игровой
  ACitySedan — Pawn и в этот фильтр не попадает. Список удалённых акторов находится
  в Saved/CityV11.json. Машины, объединённые в одну сетку со зданием, потребуют
  раздельного редактирования; скрипт не удаляет здания по материалу автомобиля.
- SkyAtmosphere заменяется двухсторонней Unlit IsSky-сферой с градиентом. Это
  простое мобильное небо без атмосферного рассеяния; исправляется источник
  сообщения «On mobile the SkyAtmosphere component needs a mesh…», текст ошибок
  не скрывается консольными командами. Граф и оттенок нужно проверить на телефоне.
- Отключены Lumen, ray tracing, mesh distance fields, virtual shadow maps,
  Substrate и Mobile HDR. Карта получает простой свет, отключённые тени
  статических акторов и ограничение дистанции прорисовки небольших объектов/
  зданий. Дороги и тротуары не отсекаются по дистанции. На Android профиль
  ограничивает FPS 30, масштаб MobileContentScaleFactor=1 (~720p-база),
  отключает тени и дорогие экранные эффекты. Меняются освещение и детализация
  вдали; настройка намеренно ориентирована на телефон.

## Проверка

Без Unreal в облаке выполняются C++-проверки джойстика/педалей/динамики при разных
FPS, Python-проверки фильтра городских машин, Blender-подготовка тестовой сцены
и проверки синтаксиса. Подтверждены 0 начального ввода при новом центре, мёртвая
зона, ограничение отклонения, монотонный переход назад→вперёд и приоритет педалей.
Свойства редакторского Python сверены с документацией UE. Не выполнены компиляция
Unreal C++, AAPT/Gradle, измерение FPS и визуальная проверка телефона.

После обновления протестировать: джойстик у разных краёв, газ+руль+камера
одновременно, удержание газа при заднем ходе, тормоз при движении вперёд,
отпускание одной из двух педалей, игровую машину и отсутствие декоративных,
цвет неба без предупреждения, въезд/выезд со двора и нагрев/частоту кадров
в течение 10 минут. Если всё ещё тормозит, нужны модель телефона, RAM и
статистика CPU/GPU для следующего этапа: LOD/разбиение больших сеток и уменьшение
числа материалов. Нельзя обещать стабильный FPS без такого замера.

Журналы обновления: Saved/CityUpdateV11/<номер>/Build.log и Update.log.
Первая сборка после изменения renderer settings пересобирает шейдеры.
APK-скрипт проверяет, что обновление карты выполнено для текущего marker.
При новой чистой установке города UpdateCityV11 нужно выполнить снова.
