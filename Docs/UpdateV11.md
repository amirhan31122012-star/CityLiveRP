# CityLive RP 1.1.2 — графика первой APK и нужные функции

1. Закройте Unreal Engine и обновите feature/android-touch-controls через
   Fetch origin → Pull origin в GitHub Desktop. Если обновлению мешает
   Config/DefaultEngine.ini, сначала Branch → Stash All Changes, затем Pull.
   Не возвращайте старый renderer config через Restore stash поверх обновления.
2. Запустите RestoreCityV1.cmd. Дождитесь сообщения «Готово».
3. Запустите BuildAndroidV1.cmd. Установите новый CityLiveRP-arm64.apk поверх
   установленной игры. Пакет и подпись остаются прежними; StoreVersion=4,
   VersionDisplayName=1.1.2-test. Заранее удалять игру не требуется.

## Что восстанавливается

RendererSettings совпадают с первой APK (состояние 545f1d3): возвращаются
Mobile HDR по умолчанию, прежние настройки Substrate, Lumen/reflections,
mesh distance fields, ray tracing и virtual shadow maps. Поддержка конкретных
эффектов на телефоне по-прежнему определяется Unreal и OpenGL ES.
Удалён добавленный в 1.1 Android-профиль, который принудительно снижал качество,
дальность, разрешение и ограничивал FPS 30. Новых ограничений качества нет.

Одного изменения ini недостаточно: 1.1 записывала отключённые тени и сокращённую
дальность в сам уровень. RestoreCityV1 копирует сохранённую карту
CityLive_BeforeV11 в новый Run_<номер>/CityLive_ModernCity. Так возвращаются
оригинальные параметры освещения, тени и дальность каждого объекта.
Текущая карта и исходная копия остаются на месте. Если прежней копии нет при
наличии marker обновления 1.1, скрипт останавливается и сообщает об этом;
значения освещения не угадываются. При чистом импорте используется текущая
ещё не изменённая карта. Повторный запуск снова использует исходную карту.

Сетки, PBR-материалы, текстуры и персонаж не переимпортируются и не упрощаются.
Ограничения текстур, уже применённые до первой APK, сохраняются как в той
сборке. OptimizeCityTextures.cmd при восстановлении и сборке не запускается.
Это возврат к качеству первой APK, а не к исходным изображениям Fab до её сборки.

## Что сохраняется из обновления

- Плавающий джойстик: область начала касания — левые 40% и нижние 45% экрана.
  Центр появляется под пальцем; свайп камеры и остальные кнопки сохраняются.
- При удержании газа на заднем ходу машина сначала тормозит, затем ускоряется
  вперёд без отпускания кнопки. Последняя нажатая педаль имеет приоритет.
- Удаляются отдельные StaticMeshActor с именами Car/Cars/Vehicle/Bus/Truck/Van,
  включая Parking_Block_Cars. Игровой ACitySedan — Pawn, он сохраняется.
  Машины, слитые со зданием в одну сетку, по этому фильтру не удаляются.
- SkyAtmosphere заменяется двухсторонней сферой с материалом Unlit IsSky.
  Так устраняется источник мобильного предупреждения про SkyAtmosphere.
  Это голубое небо с градиентом, без атмосферного рассеяния. Другие ошибки
  не скрываются командами. Остальные параметры освещения берутся из V1.
- Значок с тигром и иллюстрация города на заставке сохраняются.

Старый UpdateCityV11.cmd теперь вызывает то же восстановление V1 и больше
не применяет отключение теней или дальности. Blender не запускается.
После сохранения новой карты обновляются Saved/ModernCityMap.txt,
Saved/CityV11.json и startup map. APK-проверка требует version=1.1.2,
graphics_baseline=v1 и mobile_sky=true; старого marker от 1.1 недостаточно.
Логи: Saved/CityUpdateV11/<номер>/Build.log и Update.log.

Если предыдущая попытка завершилась с World Memory Leaks в LoadLevel, обновите
репозиторий и повторите RestoreCityV1.cmd. Скрипт освобождает Python-ссылку на
созданный UWorld до загрузки карты. Незавершённая копия от прошлой попытки
не активируется; новая попытка использует другую папку Run. Удалять город,
заново импортировать ассеты или перенастраивать SDK не требуется.

## Проверка и ограничения

В облаке проверяются выбор прежней карты, сохранение исходных уровней,
восстановление параметров света и дальности, сохранение игровой машины и
отсутствие переключения карты при ошибке сохранения через подмену API Unreal.
Проверяются материал неба, джойстик и переходы педалей. Настоящие Unreal C++,
шейдеры, упаковка Android и запуск телефона здесь недоступны.

После смены renderer settings пересборка шейдеров может занять долгое время.
APK собирается без iterativecooking, чтобы прежняя готовка не использовалась
как инкрементальное обновление. Старые APK в Releases не удаляются.

Причина вылета последней версии не установлена. Возврат к параметрам первой
сборки не гарантирует исправление: на телефоне нужно проверить запуск, небо,
тени, поездку, газ при движении назад и джойстик. Если снова вылетает,
CollectAndroidCrash.cmd собирает AndroidCrash.txt по инструкции AndroidCrash.md.
