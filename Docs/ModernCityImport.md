# Локальный импорт Modern City

Источник: [Modern City Environment — OTOY360studios](https://www.fab.com/listings/6e72d76b-9cf9-4391-aa38-69772d666ac4).
Пользователь скачал city.zip. Бесплатная цена и Personal/Professional Standard
указаны на странице; сохраняйте лицензию из окна получения. Исходники этого
набора не добавляются в Git.

1. Оставьте все распакованные папки внутри
   `C:\Projects\CityAssets\ModernCity\City_Exports`.
2. Обновите ветку в GitHub Desktop и закройте Unreal Engine.
3. Дважды нажмите ImportModernCity.cmd. Blender используется установленный,
   как для подготовки дверей; ручная работа в нём не нужна.
4. После сообщения «Готово» откройте BuildAndOpen.cmd.

Поддерживается именно показанный экспорт: шесть папок GLTF — Building,
Green Area, Parking, Road, Sidewalk, Towers. FBX-дубликат Building не используется.
В каждой папке нужны GLTF/GLB, BIN и все текстуры без переименования.
Если Green Area или Towers не содержит полигональной геометрии, раздел
пропускается с CITYLIVE_CITY_SKIP_EMPTY в Prepare.log и записью skipped_parts
в manifest.json. Остальные разделы обязательны. Отсутствующие файлы или битые
текстуры не пропускаются. Пустой парк сам по себе не создаёт зелёную зону. Можно
перетащить другую корневую папку на CMD, если путь изменился.

Сначала проверяются ссылки на файлы и размеры буферов. Затем Blender запекает
мировые трансформации в вершины, сохраняя расположение частей, и создаёт FBX
со встроенными текстурами. Только у Traffic Lights внутри Road применяется
Decimate 15%; уменьшение числа треугольников не гарантирует нужный FPS.
Геометрия и материалы источника не меняются. Nanite не включается.

Каждый запуск создаёт новую карту и ресурсы в
`/Game/CityLiveMaps/ModernCity/Run_<номер>/CityLive_ModernCity`.
Существующие карты не перезаписываются. Коллизия статических объектов — по
треугольникам, чтобы общая выпуклая оболочка зданий не закрывала проезды.
Это стартовое решение для проверки, а не оптимизированная физика телефона.
Максимальный размер текстур при сборке ограничен 2048. Спавн ищется лучом
на плоской поверхности дорожного участка. После успешного сохранения карты
меняются GameDefaultMap и EditorStartupMap; прежняя карта остаётся в Content.

Журналы и промежуточные файлы: Saved/CityImport/<номер>/.
Присылайте Prepare.log (Blender), Build.log (C++) или Import.log (Unreal).
В случае ошибки стартовая карта не меняется, новая папка может остаться частичной.

В облаке проверяются Python и подготовка тестовой сцены в Blender. Импорт API UE,
коллизии, цвета и посадку спавна нужно проверить локально: движка в облаке нет.
Некоторые сложные Blender/glTF-материалы FBX не переносит полностью; если появятся
серые/прозрачные поверхности, нужен скриншот и Import.log для доработки материалов.
Также проверить: масштаб дверей относительно человека, бордюры, дворы,
отсутствие невидимых стен, езду, текстуры и FPS. Это современный город из набора;
российские вывески и оформление ещё не добавлены.

Текущий BuildAndroidV1.cmd рассчитан на прежний CityLive_V1. Не использовать его
для выпуска нового города до проверки и обновления процесса упаковки.
