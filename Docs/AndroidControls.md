# Управление CityLive RP для Android

## Управление

- Один джойстик слева: движение. Направление фиксируется относительно камеры
  при начале касания, поэтому автоматический поворот камеры не закручивает движение.
- Два нажатия на джойстик с интервалом до 0,3 секунды: присесть / встать.
- Кнопка «БЕГ» справа: удерживать для ускорения, отпустить для обычной скорости.
- Два нажатия на «БЕГ» с интервалом до 0,3 секунды: прыжок.
- Можно двигаться левым пальцем и управлять бегом/прыжком правым одновременно.
- Камера плавно следует за поворотом персонажа сзади. Второго джойстика нет.

Управление создаётся в C++ контроллером CityLiveRPPlayerController. Стандартный
сенсорный интерфейс и виджет управления шаблона заменяются этим интерфейсом.
Не требуется создавать новый виджет Blueprint или менять двоичные ресурсы.
Механика приседания использует стандартный CharacterMovement (капсула и скорость).
Отдельная анимация приседания не добавлена: её нужно подключить в анимационном
Blueprint, иначе правильная поза персонажа визуально не гарантирована.
Это локальное управление прототипа; сетевые механики в этой задаче не добавлялись.

## Проверка на Windows

1. Закрыть Unreal Editor перед обновлением исходников.
2. Открыть проект CityLiveRP в Unreal Engine 5.8 и пересобрать модули.
   При необходимости: правой кнопкой по CityLiveRP.uproject → создание файлов
   проекта Visual Studio, затем сборка CityLiveRPEditor, Development Editor, Win64.
3. Открыть карту Content/ThirdPerson/Lvl_ThirdPerson и нажать «Играть».
4. Экранное управление включено и на компьютере; мышь имитирует одно касание.
   Нажимать и перемещать левый джойстик, затем проверить правую кнопку.
   Два пальца одновременно нужно проверять на сенсорном устройстве.

## Обязательная проверка на Android

- Пройти вперёд, назад и в стороны; камера должна плавно оставаться сзади.
- Удерживать джойстик 10 секунд: персонаж не должен самопроизвольно идти по кругу.
- Двойным касанием джойстика присесть, повторным встать; под низким потолком
  вставание должно блокироваться стандартной проверкой CharacterMovement.
- Двигаться и удерживать «БЕГ» вторым пальцем; отпускание возвращает обычную скорость.
- Дважды нажать «БЕГ» во время движения: один прыжок, без зависания ускорения.
- Отпустить пальцы в разном порядке и за пределами окружностей: остановка и сброс бега.
- Свернуть и вернуть приложение во время бега: старые касания должны сброситься.
- Проверить размещение элементов на экранах разных пропорций и с вырезами.

## Статус проверки

Unreal Engine и Android SDK в облачной среде отсутствуют. Сборка UE 5.8,
визуальная проверка и запуск на телефоне здесь НЕ выполнялись. Проверка исходников
и git diff --check не заменяют эти проверки. Для APK требуется отдельно настроить
совместимый с UE 5.8 Android SDK/NDK по документации установленной версии движка.
