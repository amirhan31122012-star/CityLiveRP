# Установка четырёх настоящих дверей

Из предоставленного пользователем FBX подготовлена отдельная версия седана:
SK_CitySedan_4Doors. Геометрия передаётся в чате и не публикуется в GitHub.
Четыре новые кости: Door_Front_Left, Door_Front_Right, Door_Rear_Left,
Door_Rear_Right. К ним привязаны наружные панели, внутренняя обшивка, стёкла,
ручки и передние зеркала. Стойки кузова, крыша, сиденья и приборная панель
остаются неподвижными. Сохранены колесные кости и SteeringWheel.

## Установка без ручной настройки материалов

1. Скачать новый FBX из чата и получить обновления feature/android-touch-controls.
2. Закрыть Unreal Engine.
3. Дважды щёлкнуть ImportSedanDoors.cmd в папке CityLiveRP и выбрать скачанный
   **SK_CitySedan_4Doors_v2.fbx** в окне выбора. Можно также перетащить FBX на этот файл.
4. Дождаться сборки кода, запуска полного редактора, импорта и его закрытия.
5. Запустить BuildAndOpen.cmd и проверить посадку/выход через каждую дверь.

Импортёр создаёт отдельную сетку и скелет по пути
`/Game/CityLiveVehicles/Sedan/SK_CitySedan_4Doors`. Исходный Fab-ресурс не меняется.
Назначения материалов копируются с локального SK_Sedan_01a по именам слотов
и материалов, с резервным соответствием по сохранённому порядку четырёх слотов.
Если новый ресурс уже существует, скрипт останавливается, не затирая ручные правки.
Завершение подтверждается отдельным маркером Saved/VehicleImport/Import_*.ok.

Исходный SedanForDoors_*.fbx содержит только неподвижные двери и для установки
не подходит. Перед импортом проверяются имена новых дверных костей в FBX,
а после импорта — наличие всех четырёх костей в созданной сетке Unreal.
Если модель не установлена, при посадке игра сообщает об этом: одного Pull origin
недостаточно, чтобы заменить локальный ресурс машины.

Код выбирает новую сетку, когда она установлена; иначе использует исходную.
Петли и точки ручек привязываются к новым костям в пространстве компонента.
Физика кузова, четыре места, выбор ближайшего пассажирского места и колесные
анимации сохраняются. Производный ресурс также исключён из публичного Git.

## Что проверено

В Blender импортирован исходный FBX и экспортирована версия с десятью костями.
Число вершин 86576 и треугольников 129878 не изменилось. Четыре материала
сохранены в исходном порядке, UV и вершины не пересоздавались. Веса нормированы.
Подготовленный FBX повторно импортирован: габариты 4,9279 × 2,1509 × 1,4346 м,
имена десяти костей и число треугольников сохранились.

Каждая дверь отдельно повёрнута на 65 градусов. Проверены движение её вершин,
неподвижность остальных частей и отсутствие растяжения рёбер треугольников.
Максимальная численная погрешность нецелевых вершин — менее 0,002 мм.
Выполнен просмотр открытых дверей в рендере Blender.

## Что ещё проверить в Unreal

Импортёр и игровой запуск не выполнялись в облаке: Unreal здесь отсутствует.
На Windows нужно подтвердить масштаб, направление открытия, материалы, высоту
ручек и позы персонажа в четырёх проёмах. Закрытые двери должны совпадать с кузовом,
а при посадке должна открываться только выбранная дверь.

Скрипт подготовки доступен как Scripts/PrepareSedanDoorsBlender.py. Он содержит
только алгоритм для этой версии экспортированного седана, без самой модели:

```sh
blender -b --python Scripts/PrepareSedanDoorsBlender.py -- input.fbx output.fbx
```

При повторной обработке выбирайте новое имя output.fbx: скрипт не перезаписывает
существующий результат. Работать нужно с исходным FBX без добавленных дверных костей.
