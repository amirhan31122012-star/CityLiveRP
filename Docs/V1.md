# CityLive RP V1 — подготовка тестовой версии

**План изменён:** пользователь отклонил карту из примитивов. Её автоматическое
создание отключено; скрипт CreateV1Map.py оставлен для истории прототипа.
Ниже описан прежний прототип, а не утверждённая карта выпуска.
Текущий план окружения: Docs/CityMap.md.

Первая карта: район 360 × 360 метров, дороги шириной 12 метров, девять
перекрёстков, четыре двора с восемью домами, парковка рядом с точкой появления.
Это первая геометрия района, без интерьеров, трафика и сетевой игры.

Закройте Unreal, обновите ветку в GitHub Desktop и запустите BuildAndOpen.cmd.
Ранее после установки персонажа скрипт создавал карту локально и назначал
её стартовой. Сейчас это отключено. Существующую CityLive_V1 он не перезаписывает. При ошибке пришлите
Saved/Logs/CityLiveRP.log. Генератор: Scripts/CreateV1Map.py.

Перед APK проверьте в редакторе: появление персонажа и машины, езду через все
перекрёстки, газ и задний ход, четыре места, двери, посадку, выход, приседание,
свайп камеры и текстуры персонажа. Затем проверьте эти действия на телефоне.
В облаке Unreal и Android SDK отсутствуют: карта ещё не проверена в движке.

Для Android сначала установите SDK/NDK через настройки платформы Android в UE.
Выберите Android, ARM64, формат текстур ASTC и упакуйте Development-сборку в
отдельную папку вне проекта. Нельзя считать V1 выпущенной до успешной сборки и
проверки на телефоне. Для магазина отдельно нужны подпись и карточка приложения.

В распространяемую версию включите Docs/CharacterCredits.md и лицензию модели
персонажа вместе с указанием изменений из Assets/Characters/Beige/README.md.
До публичного выпуска проверьте права на используемый Fab-пакет автомобилей.
Модель персонажа высокополигональная; производительность Android пока не измерена.
