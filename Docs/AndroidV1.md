# Тестовый APK CityLive RP V1

Это локальная Development-сборка ARM64 с текстурами ASTC для личного тестирования.
Данные упакованы внутрь APK, публикация в магазине не выполняется.
Нужен Android-телефон с ARM64 и поддержкой ASTC/OpenGL ES 3.2.

1. Сначала завершите ImportModernCity.cmd и проверьте город. Затем обновите
   проект в GitHub Desktop. Повторный импорт после обновления не требуется.
2. В Unreal откройте «Правка → Настройки проекта → Платформы → Android».
   Если требуется настройка проекта для Android, нажмите соответствующую кнопку.
   Примите лицензию Android SDK, если редактор предлагает это действие.
3. Через меню «Платформы → Android» проверьте состояние SDK. Если он не установлен,
   используйте предложенную Unreal установку SDK/Turnkey. Названия пунктов могут
   отличаться в переводе UE. Версии SDK/NDK выбирайте по требованиям установленного UE.
4. Закройте редактор. Откройте BuildAndroidV1.cmd двойным щелчком.
5. При успехе откроется Releases/AndroidV1. Найдите APK внутри созданных подпапок.
6. Скопируйте APK на телефон, откройте его и разрешите установку из этого источника,
   если Android запросит. Это тестовая версия вне магазина.

Если проверка SDK не проходит — пришлите Saved/VerifyAndroidSDK.log. Если не проходит сама сборка —
Saved/BuildAndroidV1.log. Сборка Windows не проверяет наличие Android SDK.

Проверьте на телефоне: запуск, цвет персонажа, джойстик, свайп камеры одновременно
с газом, тормоз/задний ход, четыре места, двери и поездку по району в течение 10 минут.
Зафиксируйте модель телефона, частоту кадров, нагрев и вылеты. Проект ещё не прошёл
проверку Android; готовность V1 определяется этим тестом, а не наличием скрипта.

Перед распространением другим людям добавьте в игру раздел авторов с данными из
Docs/CharacterCredits.md и проверьте условия Fab-пакета автомобилей. Текущий APK
не содержит отдельного экрана авторов. Для магазина потребуется отдельная подпись.

Сборка выбирает карту по Saved/ModernCityMap.txt, записанному успешным импортом.
Перед упаковкой проверяет существование карты и персонажа и восстанавливает
GameDefaultMap/EditorStartupMap на этот город в локальном DefaultEngine.ini.
Новая карта после каждого импорта получает номер Run; путь не задаётся вручную.
Старая площадка CityLive_V1 больше не включена в MapsToCook. Производная модель
автомобиля из CityLiveVehicles включается в упаковку для динамической загрузки.
Каждая сборка сохраняется в отдельную подпапку Releases/AndroidV1/<номер>, чтобы
невозможно было принять APK предыдущей сборки за новый. Исходники города повторно
не обрабатываются. Статические припаркованные машины набора не являются игровыми.

Скрипт проверен статически; Windows/UAT/Android SDK отсутствуют в облачной среде.
Фактическая сборка и производительность на телефоне ещё не проверены.
