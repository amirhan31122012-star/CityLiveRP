# CityLive RP V2 — 2.0.0-test

Рабочая V1 сохранена в истории Git: `43d19a8` (1.2.2-test). V2 продолжает ту же карту и настройки графики.

## Что добавлено

- Новый профиль получает **20 000 ₽ один раз**. Заработка и списаний пока нет. Ник и баланс видны справа сверху.
- Вход: отдельные поля имени и фамилии, кнопка «Играть», затем пароль. Каждое поле имени — 2–20 английских букв. Регистр имени не создаёт другой аккаунт: Ivan_Ivanov и IVAN_IVANOV — один профиль.
- Для нового ника предлагается создать и повторить пароль (6–64 символа). Для существующего — ввести ранее установленный пароль.
- Последний использованный ник подставляется при следующем запуске. Пароль всегда вводится заново.
- После повторного входа можно выбрать начальный спавн или место последнего выхода и нажать «Далее». Новый профиль сразу входит на начальном спавне.
- Позиция сохраняется раз в 5 секунд, при сворачивании и штатном выходе. Падение и переход через дверь не перезаписывают безопасную точку. После выхода из игры в автомобиле игрок возвращается пешком в эту точку; машина не сохраняется.
- Три двусторонние голубые метки **P** на парковке возле полиции висят на уровне торса. Подойдите ближе 1,5 м: откроется выбор машины. Выберите «Седан», затем «Вызвать автомобиль». Игрок сразу оказывается за рулём на свободном ровном месте рядом. В начале игры машины нет.
- Повторный вызов заменяет предыдущую машину после успешного появления новой. Если место занято, старая остаётся. После отмены меню отойдите от метки дальше 2,6 м и подойдите снова.
- За рулём есть спидометр в км/ч и отдельная удерживаемая кнопка «ДРИФТ» слева от кнопки двери. На компьютере — пробел. Сцепление меняется плавно; эффект усиливается с 14 до 36 км/ч. Отпустите кнопку для восстановления сцепления. Педаль тормоза по-прежнему отвечает за торможение и задний ход.

## Профили пока локальные

Подключённого сервера нет. Ник, пароль, деньги и позиция относятся к сохранениям этого приложения на этом устройстве. На другом телефоне это отдельный профиль; уникальность ника между телефонами и защита баланса от изменения требуют сервера. Это не сетевой аккаунт Black Russia.

Для файлов приложения включён `bUseExternalFilesDir=True`, чтобы использовать каталог приложения без запроса доступа ко всем файлам телефона. Пароль в открытом виде не сохраняется: используется PBKDF2-HMAC-SHA1, 100 000 итераций, отдельная случайная соль для каждого профиля. Локальная проверка пароля не заменяет серверную авторизацию. Нельзя восстановить забытый пароль через почту. При удалении приложения или очистке его данных локальные профили могут быть потеряны. Устанавливайте обновлённый APK поверх предыдущего, сохраняя ту же подпись.

## Как собрать

1. Закройте Unreal Editor. В GitHub Desktop выполните Fetch/Pull.
2. Запустите **`BuildAndroidV2.cmd`**. Это Shipping ARM64 ASTC, тот же пакет `com.cityliverp.game`, Android StoreVersion 8.
3. По окончании откроется `Releases\AndroidV2\Shipping\<номер>`. На телефон передаётся **`CityLiveRP-Android-Shipping-arm64.apk`** — файл без `AFS_`.
4. Установите поверх текущей версии. Повторный импорт города, запуск Blender и обновление света для V2 не нужны, если V1 1.2.2 уже работала.

Журнал V2: `Saved\BuildAndroidV2Shipping.log`; проверка SDK: `Saved\VerifyAndroidSDK.log`. Старые файлы сборки V1 продолжают работать как общие сборщики текущего кода; для точного повторения V1 используется её коммит.

## Проверка на телефоне

1. Запустите приложение: машины рядом с начальным спавном быть не должно. Зарегистрируйте Ivan_Test с новым паролем. Баланс — 20 000 ₽.
2. Подойдите к парковке возле полиции. Проверьте видимость P с обеих сторон. Отмените меню; оно не должно открыться снова, пока вы не отойдёте от метки.
3. Выберите седан и вызовите его. Проверьте посадку сразу за руль, газ, тормоз, спидометр, удержание дрифта вместе с газом и рулём. После сворачивания газ и дрифт должны отпускаться.
4. Выйдите из машины и вызовите её повторно. Старой машины остаться не должно. Пройдите в другое место, подождите 5 секунд, сверните и закройте игру.
5. При новом запуске имя подставляется. Неверный пароль должен отклоняться. После правильного выберите последнее место выхода. Затем проверьте вход на начальном спавне. Баланс не должен начисляться повторно.
6. Проверьте другой ник: отдельный новый профиль получает 20 000 ₽.

## Что проверено в облаке

Переносимые C++ проверки правил имени, PBKDF2 по RFC 6070 и OpenSSL, дрифта и торможения; прежние проверки руления/педалей и подвески; Python проверки импорта/освещения. Геометрия FBX проверяется в Blender: три метки попадают на плоскую парковку полиции.

Автотест Unreal `CityLive.V2.ProfilePersistence` добавлен для проверки пароля, начального баланса и сохранения/загрузки профиля. Его можно запустить через Session Frontend → Automation в редакторе. В облаке Unreal Engine и Android SDK отсутствуют: сборка UE, экранная клавиатура и поведение машины требуют проверки на Windows и телефоне.
