# 1.2.2 — положение машины и загрузка с процентами

1. Закройте Unreal и обновите ветку в GitHub Desktop.
2. Выполните UpdateDistrictPolish.cmd: сборка нового C++, проверка света и
   подготовка небольшого стартового уровня/изображения интерфейса.
3. После «Готово» запустите BuildAndroidV1Shipping.cmd. Новый APK 1.2.2-test,
   StoreVersion=7, устанавливается поверх предыдущего. Повторный импорт города
   не требуется. При ошибке нужны Build.log, Import.log или Loading.log из
   Saved/PoliceDistrictPolish/<номер>.

У машины центр масс по XY переносится в центр четырёх опор, полученных из
костей модели, и опускается на 12 см. Равные преднагрузки пружин теперь не
создают постоянный момент тангажа/крена при асимметричных осях. Высота появления
равна RestLength+WheelRadius=62 см вместо 65 см. Подвеска продолжает работать
на склонах; принудительного выравнивания машины каждый кадр нет.
Гипотезу причины исходного перекоса нужно подтвердить в самой игре.

Запуск Android: системная заставка → маленький CityLive_Boot → экран загрузки
с иллюстрацией, полосой и процентами → текущий город. Проценты берутся из
FStreamableHandle для асинхронной загрузки карты, модели персонажа/материала
и модели машины, без таймера и искусственного замедления. При быстрой загрузке
полоса может перескакивать. При 100% показывается «запуск города» до события
PostLoadMapWithWorld. Это прогресс данных карты, а не точный процент подготовки
GPU/шейдеров или запуска Android. Начальная нативная заставка процентов не имеет.

PrepareCityLoading.py создаёт boot-уровень и T_LoadingCity в отдельном процессе
редактора, чтобы не удерживать Python-ссылки на прежний мир при смене уровня.
PrepareAndroidCity.ps1 выбирает boot для GameDefaultMap, город для EditorStartupMap
и сохраняет путь города в конфиге GameInstance. Cook включает только boot и
новый город, прежняя карта не возвращается. Сцена в редакторе открывается сразу
в городе; экран загрузки проверяется в установленном APK.

В облаке проверяется математика равновесия опор и устойчивость пружин на разных
FPS, расчёты руления и Python-часть. Unreal C++, подготовка boot-уровня,
реальная загрузка/проценты и положение машины требуют проверки на компьютере
и телефоне пользователя.
