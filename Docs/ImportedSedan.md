# Подключение Vehicle Variety Vol 2

Модель устанавливается пользователем через Fab и миграцию ресурсов в проект.
Исходные файлы набора не входят в репозиторий; Content/VehicleVarietyVol2 исключён
из Git. Загрузка кода через GitHub не загружает сам набор на другие компьютеры.

Ожидаемый ресурс:

`/Game/VehicleVarietyVol2/Skeletons/SK_Sedan_01a.SK_Sedan_01a`

При запуске CitySedan загружает его через SedanMeshAsset, сохраняет назначенные
в сетке материалы, центрирует модель по XY и располагает низ модели на уровне
колёс тестового автомобиля. Масштаб сетки автомобиля остаётся исходным.
В журнале появляется «CityLive sedan: imported model active». Если загрузка не
удалась, остаётся прежний кузов и выводится предупреждение с ожидаемым путём.

UPoseableMeshComponent вращает Wheel_Front_Left/Right, Wheel_Rear_Left/Right и
SteeringWheel. Передние колёса также поворачиваются при рулении. Положение костей
рассчитывается от исходной позы, без накопления вращения от кадра к кадру.
Радиус качения пока принят 32 см; ось руля и направление вращения требуют
проверки на исходном ресурсе.

## Известное ограничение дверей

В показанном пользователем скелете есть только корень, руль и четыре колеса.
Костей дверей нет. Тестовые двери скрываются вместе с кубами; настоящие двери
ресурса пока НЕ открываются. Процедурная последовательность посадки сохранена,
поэтому на данном этапе она может пересекать закрытые двери новой модели.
Для полноценной посадки нужно экспортировать сетку из Unreal в FBX, отделить
двери и добавить их кости/петли, затем настроить точки рук и сидений. Одного пути
к ресурсу недостаточно для такой доработки: его геометрия отсутствует в облаке.

## Проверка в Windows

1. Скачать обновление feature/android-touch-controls, закрыть редактор и запустить
   BuildAndOpen.cmd. Fab-ресурсы должны уже находиться в локальном Content.
2. На ThirdPerson карте должен появиться седан с материалами вместо кубов.
3. Проверить высоту над землёй, направление кузова и камеру.
4. Проехать вперёд и назад; проверить вращение колёс, передний поворот и руль.
5. Проверить места и высоту головы: точки сидений пока соответствуют прототипу
   и могут потребовать подгонки под новую сетку.

Автомобиль использует увеличенную коробку коллизии 500×240 см, соответствующую
видимым на снимке габаритам модели около 493×237 см. Проверка ровной площадки
покрывает 520×270 см; точки подхода/выхода отнесены на 190 см от центра.

Компиляция UE, изображение и загрузка ресурса в облаке не проверены: ни самого
ресурса, ни установленного Unreal Engine здесь нет. Перед Android-сборкой нужно
также подтвердить включение сетки и её зависимостей в cook и проверить LOD/материалы
на телефоне. Код подключения не является проверкой производительности Android.
