# CityLive Android Launcher 0.1.0

Оригинальное отдельное Android-приложение: адрес сервера, ник First_Last,
проверка онлайна SA-MP UDP info, копирование адреса и запуск установленного
клиента через `samp://IP:порт?nickname=First_Last`. По умолчанию указан
5.181.187.57:7811; адрес можно поменять, если сервер пересоздан.

**Это лаунчер, не игровой клиент.** В нём нет GTA-движка, игровых ресурсов,
голосового чата или собственного управления автомобилем. Он не запускает
старый CityLive Unreal APK. Совместимый игровой клиент устанавливается отдельно.
Не все Android-клиенты обрабатывают `samp://` и параметр nickname; в таком случае
добавьте адрес и ник вручную в настройках клиента. Если обработчика ссылки нет,
приложение покажет понятное сообщение.

Приложение хранит только адрес и ник в приватных настройках. Пароль персонажа
не запрашивает. Разрешение только INTERNET; микрофон, контакты и общий доступ к
файлам не нужны. Серверные строки и длины пакета проверяются перед отображением.
Минимальная версия Android 8.0 (API 26), target/compile API 35.

## Сборка

Открыть каталог AndroidLauncher в актуальном Android Studio, установить Android
SDK Platform 35 и Build Tools 34.0.0, выбрать JDK 17 и Gradle 8.9. Если Studio
предлагает обновление AGP, для воспроизведения текущей сборки оставить 8.7.3.
В Windows из этого каталога: `gradlew.bat :app:assembleDebug :app:lintDebug`;
в Linux/macOS: `./gradlew :app:assembleDebug :app:lintDebug`. Wrapper скачает
закреплённый Gradle и проверит его SHA256.

Или Docker:

```
docker build -t citylive-launcher AndroidLauncher
docker run --rm -v "$PWD/AndroidLauncher/Packages:/out" citylive-launcher
```

APK из `Packages/CityLiveLauncher-0.1.0-debug.apk` подписан отладочным ключом
сборочной среды. Это устанавливаемая сборка для проверки; ключ не публикуется.
Для обновляемого публичного приложения нужна собственная постоянная release-подпись.
Сборку, Lint и тест декодирования пакетов проверяем автоматически; установку
на физический телефон и открытие конкретного стороннего клиента ещё не проверяли.
