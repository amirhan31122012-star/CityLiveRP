# CityLive RP

- **Server/** — C++ серверный модуль SA-MP / samp-cpp и готовые пакеты размещения.
  Начать с [инструкции установки](Server/README.md).
- **AndroidLauncher/** — собственный Android-лаунчер с проверкой онлайна и запуском
  отдельно установленного совместимого клиента; [инструкция](AndroidLauncher/README.md).
- **Source/, Content/, Assets/** — сохранённый самостоятельный проект Unreal Engine.
  Он не является клиентом нового SA-MP-сервера.

Переход выполняется по этапам. В Server/README.md явно перечислены реализованные
системы, ещё не перенесённые возможности и ограничения проверок.
