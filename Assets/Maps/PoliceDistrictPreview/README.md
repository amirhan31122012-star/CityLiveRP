# Первый вариант квартала с полицией

Самостоятельно созданная геометрия российского района. Ассеты Black Russia
или сторонних платных наборов не использовались. Это вариант для обсуждения
внешнего вида; существующий уровень игры не заменяется.

- `Overview.png` — планировка района.
- `Police.png` — отдел полиции: вывеска, вход, ступени, навес, флаги и парковка.
- `Street.png` — вид с улицы.
- `CityLive_PoliceDistrict.blend` — редактируемая сцена Blender, размеры в метрах.
- `CityLive_PoliceDistrict.glb` — геометрия с простыми PBR-материалами для переноса.
- `GeometryStats.json` — фактические числа объектов, треугольников и групп экспорта.

В квартале есть две пересекающиеся улицы, периметральные дороги, тротуары,
разметка, переходы, полиция, жилые пятиэтажки, два девятиэтажных дома, три
магазина, деревья, скамейки, освещение и небольшая детская площадка.
Посторонних декоративных машин нет. У зданий оформлены окна, рамы, подоконники,
часть балконов, входы, межэтажные швы и детали крыши.

В .blend мелкие элементы остаются редактируемыми и используют общие сетки.
В .glb они объединены по материалу и ячейке 32 м. Это сокращает число объектов
экспорта, но число draw calls в Unreal нужно измерять отдельно.
Материалы сейчас однотонные, без фотореалистичных текстур и интерьеров.
LOD, игровая коллизия, размещение спавна, импорт в Unreal и тест Android
ещё не выполнены. Рендер Blender не является скриншотом работающей игры.
Стабильные 30/60 FPS до проверки на телефоне не заявляются.

Воспроизведение:

```sh
blender -b -t 6 --python Scripts/CreatePoliceDistrictBlender.py -- Assets/Maps/PoliceDistrictPreview
```

Нужен Blender 4.3+ и Cycles. Генератор записывает файлы в указанную папку;
для новой редакции без перезаписи выберите другую папку вывода.
