# Переработка стиля: фактурный российский квартал

Это настоящий рендер изменённой сцены Blender, а не концепт-изображение,
выдаваемое за игровую карту. Установленная карта и настройки игры не меняются.

- PoliceRealistic.png — новый вид отдела полиции.
- StreetRealistic.png — новый вид с улицы.
- CityLive_PoliceDistrict_Realistic.blend — редактируемая сцена.
- Textures/ — 17 текстур 1024×1024: PBR поверхностей, цвет и маска веток с листвой.
- TextureCredits.json — источники, прямые ссылки и контрольные суммы текстур.

Изменения относительно первого макета:

- Цвет, шероховатость и нормали для асфальта, штукатурки, кирпича, тротуаров и земли.
- UV-развёртка с масштабом в метрах.
- Геометрические шарообразные кроны заменены ветвями и текстурированными ветками с прозрачной маской.
- Затемнённое стекло, разные оконные шторы, кондиционеры.
- Парапеты, металлические отливы, водостоки и детали входа.
- Новое освещение и камеры на уровне улицы.

Текстуры: Poly Haven, CC0 (https://polyhaven.com/license).
Конкретные ассеты: asphalt_02, grey_plaster_03, concrete_pavement,
red_brick_03, grass_ground, tree_small_02 (только текстуры листвы). Сторонние модели и ассеты Black Russia не использованы.
Оригинальная геометрия создаётся скриптами этого проекта.

Сцену можно открыть в Blender 4.3+. Папка Textures должна находиться рядом
с .blend: пути относительные. Для повторной генерации:

```sh
blender -b -t 6 --python Scripts/CreateRealisticPoliceDistrict.py -- Assets/Maps/PoliceDistrictRealistic
```

Это вариант для проверки художественного стиля. Листва использует
маску прозрачности; её стоимость нужно измерить на телефоне. Готовность мобильной
карты и FPS не заявляются.
До импорта в игру нужны LOD растительности, коллизия, бюджет материалов и проверка
на телефоне. GLB первого макета этой папкой не заменяется. Для игрового экспорта
модуль CityDistrictBatch.py теперь сохраняет UV в объединённых сетках.
