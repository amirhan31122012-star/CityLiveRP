# Пакет основной карты CityLive RP 1.2

Готовый FBX и PBR-текстуры утверждённого авторского района.
Для установки в Unreal запустите ImportPoliceDistrict.cmd в корне проекта.
Повторное запекание Blender на компьютере пользователя не требуется.
Инструкция: Docs/PoliceDistrict.md.

manifest.json содержит относительные пути, стабильные имена материалов,
контрольные суммы и число сеток/треугольников. Текстуры в Textures необходимы
для импорта; одного FBX недостаточно. Не переименовывайте файлы внутри набора.

BakedPreview.png получен обратным импортом этого FBX в Blender и восстановлением
материалов из sidecar-данных. Это проверка переносимого набора, не снимок Unreal.
Оригинальная геометрия создавалась в этом проекте. Фотографические текстуры и
карты высоты — производные CC0-ресурсов Poly Haven, источники и лицензия:
../PoliceDistrictRealistic/TextureCredits.json (https://polyhaven.com/license).
