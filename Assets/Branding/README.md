# Значок CityLive RP

CityLiveTiger.png — изображение, созданное по присланному пользователем референсу
огненного тигра 29 октября 2026. Это новая композиция для значка, не исходный файл
пользователя. Без надписей; основные черты морды оставлены ближе к центру для масок
Android. Разрешение исходника генератора: 1254 × 1254.

Файлы для Android: Build/Android/res. PNG подготовлены из исходника уменьшением
с фильтрацией ImageMagick. Legacy icon.png для ldpi/mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi:
36/48/72/96/144/192 px; fallback drawable/icon.png — 144 px.

На Android 8+ drawable-anydpi-v26/icon.xml задаёт adaptive icon с тёмным фоном
и tiger foreground. Растры слоя 81/108/162/216/324/432 px соответствуют 108 dp.
Маску (круг/скруглённый квадрат) определяет лаунчер телефона. Тема monochrome
для Android 13+ отдельно не создавалась; отображается обычный цветной значок.

UE копирует переопределения Build/Android/res в Android-проект при упаковке.
Имя ресурса icon соответствует стандартной ссылке UE @drawable/icon.
Проверено: PNG-размеры, XML и ссылки на ресурсы; actual AAPT/установку APK
не проверяли в облаке. После установки проверить значок и название CityLive RP
на экране телефона. Некоторые лаунчеры могут кэшировать значок старой установки.

## Экран запуска

CityLiveLoadingCity.png — иллюстрация, созданная 30 октября 2026 по запросу
пользователя: современный город и титул CITYLIVE RP. Это не скриншот текущего
игрового уровня. Исходник генератора 1672 × 941. Он подключён к Android через
Build/Android/res/drawable/splashscreen_landscape.png (1280 × 720),
splashscreen_portrait.png (720 × 1280, иллюстрация вписана с тёмными полями),
а также downloadimageh/v.png для стандартного фона OBB-загрузчика UE.
bShowLaunchImage включён; StartupMovies очищен от унаследованных роликов.

На Android 12+ системный начальный splash может сначала показывать значок
с тигром, затем собственный launch screen игры. Поведение регулируется ОС;
полноэкранный городской экран не подменяет обязательный системный splash.
Замена ресурса не исправляет диагностируемый вылет после заставки.
Не является процентным индикатором загрузки и не добавляет реальный прогресс.
