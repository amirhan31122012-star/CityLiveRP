# Experimental rig — not ready for gameplay

Derived from **Casual Beige Knit Look** by **restore50**:
https://sketchfab.com/3d-models/casual-beige-knit-look-e92cefa2b26e47dc953cfdd16dbc076b

Licensed under **Creative Commons Attribution 4.0 International**:
https://creativecommons.org/licenses/by/4.0/

Modifications: welded coincident vertices, added a 21-bone skeleton and normalized
skin weights, adjusted arm bind poses, baked texture-coordinate transforms,
repaired some stretched faces and extracted embedded texture images.

The original scan has fused hand/clothing geometry. **Known visible defects remain
at the right hand/trousers and left armpit. This is a draft, not a finished skin.**
The runtime component is disabled by default via bEnableExperimentalSkin.
Do not treat a successful import or normalized weights as visual acceptance.
No UE compilation/gameplay verification has been performed in the cloud.
