# Границы переноса 0.1.0

Целевой стек: Linux i386 SA-MP 0.3.7 / open.mp, samp-cpp, C++17, MySQL/MariaDB.
Игра больше не требует Unreal на сервере. Старый Unreal-проект сохранён отдельно.

| Система Unreal | Новая реализация | Состояние |
|---|---|---|
| First_Last, регистрация и вход | Серверные диалоги, PBKDF2, MySQL | Код собран, БД проверена |
| Деньги, позиция, курьер | MySQL, фоновая очередь | Проверено на MariaDB |
| Пять точек появления | Выбор организации / старта / выхода / парковки / дома | Серверный код собран; визуально в клиенте ещё не проверено |
| Работа курьера | Pizza Boy, заказы, метки, 5 000 за доставку | Правила и выплата проверены; поездка игроком ещё не проверена |
| Дома и квартиры | 8 подъездов, этажи, 4 двери, покупка, отдельные интерьеры | Транзакции и владение проверены; расположение входов требует просмотра в игре |
| Полиция, больница | 3 вопроса, порог 2/3, организация и роль | Сохранение проверено; диалоги требуют просмотра в игре |
| Парковка и NPC | Merit на сеанс, актёры, надписи | Код собран; требуется проверка мест в игре |
| GPS | Метки POI, дома, машины и заказа | Серверные метки; маршрутов по дорогам нет |
| Чат | Локальный 25 м, /me /b /s, лимит частоты | Правила проверены; расположение штатное для клиента |
| Баланс | Компактный TextDraw с тёмной подложкой | Код собран; оформление на Android ещё не проверено |
| Android-запуск | Оригинальный отдельный AndroidLauncher | Лаунчер; не игровой движок |
| Карта, модели и скины Unreal | Пока используются город и модели GTA SA | Кастомные ассеты ещё не преобразованы |
| Посадка, мобильные кнопки, дрифт, радиус поворота | Штатный SA-MP/GTA-клиент | Собственная клиентская реализация ещё не сделана |
| Голос | Не реализован | Нужны клиентский аудиокод и транспорт |
| Старые профили SaveGame | Новая отдельная БД | Автоматического импорта нет |

Развёртывание на RideHost не выполнено: в рабочей среде нет сессии его панели или FTP.
Подготовлены архив и инструкция; совместимость тарифа с собственным .so и glibc 2.34+
ещё не проверена. Адрес 5.181.187.57:7811 задан в лаунчере, но доступность и содержимое
купленного сервера не выдаются за результат нашей локальной проверки.

Полноценный оригинальный Android-клиент GTA/SA-MP не создаётся переносом C++
серверного кода: нужен игровой runtime, сетевой клиент, рендер, управление и загрузка
правомерно полученных игровых ресурсов. AndroidLauncher не содержит этих систем.
Старый APK Unreal к этому серверу подключаться не умеет.
