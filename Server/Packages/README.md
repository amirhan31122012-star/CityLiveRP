# CityLive RP 0.1.1 — исправление совместимости RideHost

`citylive.so` — отдельный Linux i386 плагин для загрузки в папку `plugins`.
Остановите сервер, замените старый файл и запустите снова. Конфиг, AMX и база
версии 0.1.0 совместимы: повторно импортировать SQL или удалять данные не нужно.

Сборочная база glibc 2.27; фактически импортируемые символы — до GLIBC_2.25.
Проверены старый загрузчик и работа с MySQL. Установка на самом RideHost ещё
не проверена; ошибка GLIBC_2.33 от старого файла устранена в сборке.

Полные ZIP RideHost/VPS содержат этот же файл, AMX, инструкции, лицензии и
`relink-source/` для изменения и пересборки встроенной LGPL-библиотеки MariaDB.
Исходники также находятся в соседних каталогах `../src`, `../ThirdParty` и
`../scripts`; описание перелинковки — `../RELINKING.md`. Контрольные суммы —
`SHA256SUMS.txt`. OpenSSL 3.5.9 собирается по закреплённому официальному URL/SHA256.
