# Пересборка статически связанных библиотек

Архивы развёртывания содержат `relink-source/`: исходники CityLive, полные исходники
MariaDB Connector/C с лицензией LGPL-2.1, samp-cpp и остальных встроенных зависимостей,
CMake и Dockerfile. Здесь можно заменить Connector/C и пересобрать `citylive.so`.
Для такого изменения и перелинковки разрешены анализ и модификация серверного модуля,
включая обратную разработку для отладки изменений библиотеки, как требует LGPL-2.1 §6.
Сторонний код сохраняет собственные лицензии и уведомления об авторстве.

```
docker build -t citylive-relink relink-source
docker run --rm -v "$PWD/rebuilt:/out" citylive-relink
```

Сборочная среда использует Ubuntu 22.04, GCC 11, системные OpenSSL и zlib. Их
уведомления лежат в `licenses/`, версии исходных зависимостей — в `manifest.json`
и `relink-source/ThirdParty/sources.json`. Сборка не требует исходников Unreal,
закрытых GTA-файлов, доступа к RideHost или настоящей базе данных.
